## 偏好

- **发版才 bump**：日常修缺陷不升版本；仅用户明确说发版/打包时 patch +1，并写 CHANGELOG。
- **记忆跟仓库走**：沉淀用本文件 + 项目 skill，不绑 Cursor/Codex 专有存储。

## 易踩坑

- **元素 mode=5 结算**：故意不走通用 `find_click_return`（成功页也有「返回」会误退）。失败页无「下一关」，须先认「挑战失败」再点返回重开。
- **元素 mode=5 弹窗**：`continue` 会跳过通用「领取/首页关闭」；须在 mode=5 内复用 `find_click_receive` / `find_click_home_close`，否则巡逻奖励等弹窗会挡住历练大厅下滑。
- **衍生名 OCR**：偏好细分读卡顶正式名，不要绑死 `band_roi`。3选1 可恒开；4选2 须用更紧 ROI（约 0.72×），照搬 3选1 的 `-130/-100` 会读空再回退成效果描述 → 全 `deriv=3`。
- **元素选技能布局**：前段 4选2（`ay>280`→abyss），后段 3选1（`band_roi=False`）。

## 刻意不做
